# Random Forest feature dataset

This folder contains attack-side feature tables only. It is suitable for classifying attack module/family, not for attack-vs-normal detection unless a separate benign/control set is added.

`slot_sanity_score` means the literal fits slot constraints such as digit length, string length, and module complexity. It is not a claim of real-world traffic slot_sanity.
Runtime fields remain `not_run` until the PostgreSQL sandbox validator is executed.
