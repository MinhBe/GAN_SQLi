# SQLGAN Dual Experiment Toolkit — Kaggle Dual T4 Optimized

This toolkit runs two controlled SeqGAN experiment branches for the SQLGAN PostgreSQL Boolean V4.1 static-training corpus.

The repository currently stores the V4.1 dataset as a **static-training candidate corpus**. The README says the accepted corpus is the normal training input, and `seqgan_attack_corpus.txt` is only the raw candidate view. It also states PostgreSQL runtime checks remain `not_run`, so this toolkit does not claim runtime executability.

## Branches

### Branch A — four independent modules

```text
Y1_basic_boolean       -> train one SeqGAN
Y2_boolean_variation   -> train one SeqGAN
Y3_encoded_boolean     -> train one SeqGAN
Y4_obfuscated_boolean  -> train one SeqGAN
```

This is the old direction, kept as the baseline.

### Branch B — core + renderers

```text
Y1_basic_boolean + Y2_boolean_variation -> train core SeqGAN models
Y3_encoded_boolean                      -> render from accepted core payloads
Y4_obfuscated_boolean                   -> render from accepted core payloads
```

This is the new direction. Y3/Y4 are controlled representation layers, not separate SQL grammar learners.

## Kaggle notebooks

Use these two notebooks:

```text
notebooks/01_kaggle_branch_a_four_module_dual_t4_git.ipynb
notebooks/02_kaggle_branch_b_core_renderer_dual_t4_git.ipynb
```

Both notebooks clone GitHub, install this package, auto-detect the V4.1 ZIP in `/kaggle/input`, and run with one process per GPU.

Default branch in the notebooks:

```python
REPO_BRANCH = "sqlgan-dual-kaggle-optimized"
```

## Local installation

```bash
pip install -r requirements.txt
pip install -e .
```

## Single-module run

```bash
python -m sqlgan_dual.train_module \
  --data /path/to/SQLGAN_PostgreSQL_Boolean_Attack_Corpus_V4_1_StaticTrainingCorpus.zip \
  --out ./runs/Y1_basic_boolean \
  --module-id Y1_basic_boolean \
  --mle-epochs 12 --d-epochs 4 --adv-epochs 4 \
  --batch-size 256 --generate-n 5000 --device cuda:0
```

## Branch A CLI

```bash
python -m sqlgan_dual.experiment_a_four_modules \
  --data /path/to/V4_1.zip \
  --out ./runs/branch_a \
  --mle-epochs 12 --d-epochs 4 --adv-epochs 4 \
  --batch-size 256 --generate-n 5000
```

The branch A CLI is sequential. The Kaggle notebook is faster because it launches one module per GPU.

## Branch B CLI

```bash
python -m sqlgan_dual.experiment_b_core_renderers \
  --data /path/to/V4_1.zip \
  --out ./runs/branch_b \
  --mle-epochs 12 --d-epochs 4 --adv-epochs 4 \
  --batch-size 256 --generate-n 5000 --per-parent 2
```

The branch B CLI is sequential. The Kaggle notebook trains Y1/Y2 concurrently on Dual T4 and then renders Y3/Y4.

## Important training rule

Normal training must use:

```text
seqgan_accepted_corpus.txt
```

or the deduplicated export generated by this toolkit:

```text
seqgan_accepted_unique_corpus.txt
```

Do not train normal SeqGAN runs on:

```text
seqgan_attack_corpus.txt
```

unless intentionally testing raw-candidate noise.
