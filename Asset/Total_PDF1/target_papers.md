## 2. Research on SQL injection attacks detection method based on BERT-GAN

- Authors: LUO Yiming; TAN Yubo; LI Jianping
- Year: 2024
- DOI: 10.19304/J.ISSN1000-7180.2023.0721
- Venue: Microelectronics & Computer
- Countries: CN
- Source: journal_site
- URL: https://ycyk.spacejournal.cn/en/article/id/59361be7-e3c0-458c-80b8-270677b739a4
- PDF: https://mc.spacejournal.cn/cn/article/pdf/preview/10.19304/J.ISSN1000-7180.2023.0721.pdf

A BERT-GAN network model for detecting SQL injection attacks is proposed to improve detection accuracy when large real training datasets are difficult to obtain. The method synthesizes adversarial samples with semi-supervised learning, processes unlabeled data using fine-tuned BERT-like architectures, and uses GAN settings to distinguish adversarial/real examples and malicious/benign samples.
